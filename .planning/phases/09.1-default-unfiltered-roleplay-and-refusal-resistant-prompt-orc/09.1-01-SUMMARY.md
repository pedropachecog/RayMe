- Proved the live-call tracer: rejected attempt bytes reach no consumer, the rejected iterator closes, and accepted caption/TTS begin while both the accepted LLM and slow TTS streams remain open.

## Decisions Made

- A safe sentence or hard prefix ceiling admits original chunks irreversibly; retry is only possible before any accepted release.
- Attempts two and three append only `The prior draft broke character. Respond only with the in-world reply.` and never rejected prose.
- Runtime observability is a positive metadata allowlist and intentionally does not survive a Web process restart.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP/SSE server response -> client parser | Malformed or private server data enters browser transport handling. |
| typed client outcome -> visible thread/call DOM | Only stable codes, fixed copy, and bounded metadata may render. |
| async retry timer -> component lifecycle | Delayed UI work can race accepted content, cancellation, or navigation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09.1-12-01 | Information Disclosure | error/activity parsing and DOM | high | mitigate | Field allowlist, fixed client copy, hostile canaries, no raw detail interpolation, and metadata-only DOM assertions. |
| T-09.1-12-02 | Tampering | fragmented SSE states | medium | mitigate | Discriminated decoder, arbitrary-fragment tests, accepted content separated from control/error metadata. |
| T-09.1-12-03 | Denial of Service | retry timers | low | mitigate | Single bounded timer per active generation, synchronous clearing, lifecycle cleanup, and fake-timer leak tests. |
| T-09.1-12-04 | Repudiation | hidden/incorrect terminal result | medium | mitigate | Stable typed terminal codes, exact outcome-specific copy/actions, and zero-assistant-row assertions. |
| T-09.1-SC | Tampering | package supply chain | low | accept | No package-manager install occurs in this plan. |
</threat_model>

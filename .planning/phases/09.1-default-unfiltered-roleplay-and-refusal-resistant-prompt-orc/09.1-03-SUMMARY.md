## Decisions Made

- The shipped prompt contract is `rayme-prompt-contract-v1`; persisted nested settings use schema version `1` so reset and migration behavior remain explicit.
- Roleplay and Assistant always retain complete required prompt sets. Custom starts truthfully empty while inactive, requires Main when selected, and preserves optional Auxiliary/PHI byte-for-byte, including whitespace.
- Numeric step validation uses decimal arithmetic at the domain boundary. The Settings API requires typed JSON numbers and does not route generation values through legacy string cleaners.
- Public Settings responses enumerate allowed fields and never serialize the private API key before redaction.

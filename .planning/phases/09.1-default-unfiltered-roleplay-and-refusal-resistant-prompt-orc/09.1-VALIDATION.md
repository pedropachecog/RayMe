- **After every task commit:** Run the narrow owning test file; for client changes also run the focused Vitest command in the plan.

- **Before `$gsd-verify-work`:** Plan 14 freezes the intended SHA and runs the complete local gate from that exact clean tree.

## Fixed Acceptance Thresholds

- **REF-01:** 100% recall over 10 refusal prefixes and 100% specificity over 12 benign prefixes under all eight canonical fragmentations; zero refused bytes and zero false retries.
- **REF-02:** Exactly one to three attempts, at most two retries, distinct injected seeds, rejected stream closed before the next request, and only `llm_refusal_exhausted` after exhaustion.
- **RETRY-01:** Attempts 2 and 3 contain exactly `The prior draft broke character. Respond only with the in-world reply.`; Qwen maps it late user, Generic late system, Continue keeps assistant prefill final, and rejected prose is absent.
- **PROMPT-01:** Zero ordered-message/request-field differences across all seven consumers, all three prompt modes, and both adapters; character fields are name/description/personality/scenario in order; lorebook/world-info canary count is zero in composer/preview/wire.
- **BUDGET-01:** `input_budget = context_limit - configured_max_output - safety_margin`; non-default configured outputs change fit deterministically; mandatory overflow is typed; 48/20k applies only to AI-backend Call offers.
- **STREAM-01:** Every slow safe stream releases before upstream completion; guard CPU stays below 5 ms p95 over at least 100 feeds.
- **CALL-01 / STATE-01:** Caption and audio start before accepted LLM/TTS completion; no whole-synthesis VoxCPM2 fallback; exactly one successful persistence write and zero rejected, failed, interrupted, or late writes/events.
- **PREFLIGHT-01:** Provider-dependent work has a fresh read-only OMEN record for exact model/capacity/template/prefill; no research-time identity is accepted as observation.
- **DEPLOY-01 / PRIV-01:** One frozen SHA passes all local sources/gates, no commit intervenes before canonical deployment, the 36-turn deployed matrix has zero request/refusal/privacy failures, and the summary is committed only after deployed evidence/human verification.

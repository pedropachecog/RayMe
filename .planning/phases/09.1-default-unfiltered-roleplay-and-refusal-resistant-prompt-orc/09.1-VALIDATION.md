## Sampling Rate

- **After every task commit:** Run the narrow owning test file; for client changes also run `npm --prefix web-ui/client run test:unit -- --run`.
- **After every plan wave:** Run both pytest suites, all client unit tests, and the selected hermetic Playwright specs named by the plan.
- **Before `$gsd-verify-work`:** The full local suite and evidence-contract verifier must be green.
- **Max feedback latency:** 180 seconds for the task-level sample; split a command when it exceeds this bound.

## Fixed Acceptance Thresholds

- **REF-01:** 100% recall over 10 refusal prefixes and 100% specificity over 12 benign prefixes under all eight canonical fragmentations; zero refused bytes and zero false retries.
- **REF-02:** Exactly one to three attempts, at most two retries, distinct injected seeds, rejected stream closed before the next request, and only `llm_refusal_exhausted` after exhaustion.
- **PROMPT-01:** Zero ordered-message/request-field differences across all seven consumers, all three prompt modes, the fixed adapter matrix, and matching preview/wire builds; zero credential canaries.
- **STREAM-01:** Every slow safe stream releases before upstream completion; guard CPU stays below 5 ms p95 over at least 100 feeds.
- **CALL-01 / STATE-01:** Caption and audio start before accepted LLM/TTS completion; no whole-synthesis VoxCPM2 fallback; exactly one successful persistence write and zero rejected, failed, interrupted, or late writes/events.
- **DEPLOY-01 / PRIV-01:** The 36-turn deployed Qwen matrix has zero emitted refusals, false retries, request diffs, secrets, or raw private/rejected prose in shared artifacts.

## Decisions Made

- Centralized all prompt help in one variant-driven component so ordinary interpolation, exact wording, and responsive behavior cannot drift across fields.

- Left `mes_example` untouched as character-card content. Help does not read a thread, a legacy null example snapshot, or a later live character source.

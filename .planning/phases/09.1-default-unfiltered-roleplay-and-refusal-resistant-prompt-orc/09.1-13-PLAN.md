<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| thread/card/preview DTO -> browser DOM | Private arbitrary Unicode, markup-like text, request JSON, and activity metadata become visible. |
| drawer controls -> preview API | Local drafts, targets, and call transcript cross a same-origin non-mutating request boundary. |
| drawer async lifecycle -> page/call state | Loading/abort/focus/inert behavior can race navigation and active thread controls. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09.1-13-01 | Elevation of Privilege | prompt/JSON rendering | high | mitigate | Svelte text interpolation and escaped pre only, hostile-markup E2E fixtures, no raw HTML/Markdown parser. |
| T-09.1-13-02 | Information Disclosure | inspector/activity UI | high | mitigate | Typed DTO allowlist, fixed privacy copy, response/DOM credential-seed-rejected-text canaries, current-thread metadata only. |
| T-09.1-13-03 | Tampering | preview side effects | high | mitigate | Same-origin wrapper, explicit AbortSignal, side-effect request counters/spies, local-only call transcript, no submit handlers. |
| T-09.1-13-04 | Denial of Service | long content/loading | medium | mitigate | Contained body/JSON scrolling, wrap-anywhere, abortable requests, duplicate-preview disable, and bounded server DTO. |
| T-09.1-13-05 | Spoofing | modal focus/background | low | mitigate | Real dialog semantics, focus trap/return, inert background, expanded/haspopup state, and keyboard/backdrop tests. |
| T-09.1-SC | Tampering | package supply chain | low | accept | No package-manager install occurs in this plan. |
</threat_model>

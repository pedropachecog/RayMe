<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| persisted public settings -> editable form | Nested numeric/profile values become mutable browser state and later return to the server. |
| card/prompt text -> Svelte DOM | Arbitrary Unicode and markup-like user text enters visible Settings and Character help surfaces. |
| local font asset -> app typography | A vendored binary and license enter the shipped frontend asset graph. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09.1-08-01 | Tampering | settings numeric/profile payload | high | mitigate | Shared typed DTO, exact client validation, numeric payload capture, omission-preserving PATCH, and server-side validation retained. |
| T-09.1-08-02 | Elevation of Privilege | prompt/card rendering | high | mitigate | Ordinary Svelte interpolation only, hostile-markup fixtures, no HTML parser/unsafe Markdown, and plain-text textarea/code nodes. |
| T-09.1-08-03 | Denial of Service | long prompt UI | low | mitigate | Bounded resizable controls, wrapping, responsive containment, and server-enforced prompt/settings limits. |
| T-09.1-08-04 | Tampering | local font asset | medium | mitigate | Official immutable upstream source, WOFF2 validation, license inclusion, tracked local loading, and no runtime CDN. |
| T-09.1-SC | Tampering | package supply chain | low | accept | No npm/pip/cargo package install occurs; the font is a reviewed licensed static asset with validation. |
</threat_model>

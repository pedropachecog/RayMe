<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser Origin/body -> preview API | A potentially hostile page can submit IDs, long text, action variants, and unknown fields. |
| persisted private conversation -> public preview DTO | Exact prompt/history content becomes user-visible only through an allowlisted same-origin response. |
| preview request -> composer/adapter | Inspection must remain read-only and must not cross into seed allocation or inference. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09.1-08-01 | Spoofing | Origin validation | high | mitigate | Reuse the established explicit-Origin policy, strict POST JSON, existing CORS allowlist, and hostile-origin integration tests. |
| T-09.1-08-02 | Information Disclosure | preview DTO/errors | high | mitigate | Explicit field allowlist, response-wide secret/lorebook canaries, sanitized typed errors, same-origin enforcement, and `no-store`. |
| T-09.1-08-03 | Tampering | preview mutation | high | mitigate | Read-only snapshot/composer/adapter path plus spies forbidding generation, seeds, upstreams, writes, and persistence. |
| T-09.1-08-04 | Denial of Service | long/aborted previews | medium | mitigate | Existing settings bounds, strict body validation, deterministic prompt budgeting, cooperative cancellation, and no upstream inference. |
| T-09.1-SC | Tampering | package supply chain | low | accept | No package-manager install occurs in this plan. |
</threat_model>

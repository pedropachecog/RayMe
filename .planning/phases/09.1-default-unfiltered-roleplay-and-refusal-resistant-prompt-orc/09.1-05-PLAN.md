## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> chat/message APIs | Untrusted action identifiers, thread/message IDs, and disconnects cross into generation state. |
| server -> inference stream | Private prompt/history content leaves route code through the configured local OpenAI-compatible boundary. |
| guarded stream -> SSE/persistence | Only accepted usable assistant text and bounded metadata may cross this release boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09.1-05-01 | Information Disclosure | SSE and assistant metadata | high | mitigate | Guard before release, accepted-only persistence, typed sanitized errors, metadata allowlist, and negative leak assertions. |
| T-09.1-05-02 | Tampering | concurrent action state | high | mitigate | Frozen per-request inputs, owned streams/seeds/retry counters, staged atomic version mutation, and barrier-based concurrency tests. |
| T-09.1-05-03 | Denial of Service | retries and disconnects | medium | mitigate | Three-attempt cap, prompt stream closure on reject/cancel, bounded prefix storage, and no orphan tasks. |
| T-09.1-05-04 | Repudiation | refusal/error outcome | low | mitigate | Persist bounded outcome identifiers/counts on accepted rows and emit typed sanitized failures without private prose. |
| T-09.1-SC | Tampering | package supply chain | low | accept | No package-manager install occurs in this plan. |
</threat_model>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| persisted settings/card/thread -> composer | User-authored Unicode and macro syntax enter deterministic server-side composition. |
| composer -> adapter -> OpenAI-compatible server | Private character/history text and sampler data cross into the configured local inference boundary. |
| structured result -> later preview API | Inspectable content must remain exact text without becoming executable HTML or leaking transport secrets. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09.1-05-01 | Tampering | macro expansion and section ordering | high | mitigate | Pure one-pass expansion, immutable snapshots, stable sequence/id ordering, exact Unicode fixtures, and no content deduplication. |
| T-09.1-05-02 | Information Disclosure | structured build result | high | mitigate | Include prompt sections and public generation metadata only; omit credentials, endpoint headers, runtime seed values, and lorebook/world-info content by construction. |
| T-09.1-05-03 | Denial of Service | prompt budgeting | medium | mitigate | Subtract configured output and an explicit safety margin, drop only bounded optional groups in deterministic order, and return typed mandatory-overflow errors. |
| T-09.1-05-04 | Elevation of Privilege | preview HTML interpretation | medium | mitigate | Preserve all text as data and require downstream escaped text rendering; never generate trusted HTML from card/prompt strings. |
| T-09.1-SC | Tampering | package supply chain | low | accept | No package-manager install occurs in this plan. |
</threat_model>

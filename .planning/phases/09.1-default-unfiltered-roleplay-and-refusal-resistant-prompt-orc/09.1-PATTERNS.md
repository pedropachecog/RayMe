### Bounded prefix refusal guard below every consumer

**Apply to:** `refusal_guard.py`, `refusal_activity.py`, `llm_stream.py`, `test_refusal_guard.py`, `test_chat_stream.py`, and the call/action tests.

**Pure incremental state-machine analog:** `web-ui/server/app/domain/call_tts_segments.py` lines 12-54

```python
class CallTtsSegmenter:
    def __init__(self, *, max_words: int = 60, min_words: int = 4) -> None:
        self._buffer = ""
        self._finished = False

    def feed(self, token: str) -> list[str]:
        if self._finished:
            raise RuntimeError("call TTS segmenter is already finished")
        if token:
            self._buffer += token
        ...

    def finish(self) -> str | None:
        if self._finished:
            return None
        self._finished = True
        tail = self._buffer.strip()
        self._buffer = ""
        return tail or None
```

Copy the small explicit state object, bounded buffer, deterministic `feed()`/`finish()` contract, and invalid-after-finish guard. Do **not** call the TTS segmenter from the refusal guard or change TTS segmentation itself.

The refusal state machine must have an irreversible accepted/passthrough state. It may buffer only the bounded prefix, release early once safe, and must never inspect or retract bytes after the first accepted byte is emitted.

**Shared stream boundary:** `web-ui/server/app/domain/llm_stream.py` lines 68-140

- For a rejected attempt: emit zero bytes, close/aclose the SDK stream, draw a distinct injected seed, add only the required late correction, and retry.
- Maximum is three attempts total. Exhaustion produces typed `llm_refusal_exhausted`.
- Re-raise `asyncio.CancelledError`; cancellation closes the active attempt and starts no retry.
- Replace the current broad generic flattening at `llm_stream.py` lines 77-87 with typed safe failures while preserving the generic fallback for unknown upstream errors.

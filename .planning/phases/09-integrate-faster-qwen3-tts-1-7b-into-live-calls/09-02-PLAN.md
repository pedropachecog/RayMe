## Trust Boundaries (ASVS L1; block on high)

| Boundary | Description |
|---|---|
| Synthesis/WebRTC input → prompt preparation | User-controlled text, transcript, and audio become ICL model context. |
| Worker protocol → audio/session state | Subprocess data becomes playback and completion state. |
| Cache/model lifecycle → later requests | Ephemeral GPU prompt state can cross turns or voices if not bounded/invalidation-safe. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-09-01 | Spoofing/Tampering | Request/terminal IPC | high | mitigate | Exact request identity, monotonic sequence, one terminal, late-event rejection, worker termination. |
| T-09-03 | Tampering/DoS | Base64/reference/chunk audio | high | mitigate | Strict decoding, size/rate/finite/silence/duration bounds before prompt/playout. |
| T-09-04 | DoS | Transcript mismatch/runaway | critical | mitigate | Blank/mismatch preflight, 60-word/context bounds, text-relative token/audio ceiling, failed non-EOS terminal. |
| T-09-05 | DoS | Worker hang/crash | high | mitigate | Supervision, cancel/terminal deadlines, terminate/kill, visible Qwen-only recovery state. |
| T-09-07 | Information Disclosure | Errors/logs/status | high | mitigate | Stable codes, opaque hashes, scalar metrics, leak-scan tests; no raw voice material or paths. |
| T-09-08 | DoS | Prompt cache/concurrency/output | critical | mitigate | Capacity-one cache, one generation owner, idempotent prewarm, bounded queues/tokens/audio. |

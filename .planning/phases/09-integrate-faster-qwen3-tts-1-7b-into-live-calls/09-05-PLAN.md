| Boundary | Description |
|---|---|
| LLM token stream → speech segment scheduler | Potentially unbounded/untrusted text becomes model work. |
| Worker/native chunks → paced WebRTC track | Generated audio crosses process, async, and realtime playout boundaries. |
| Control events → terminal persistence | Interrupt/hangup/switch state decides audible output and durable history. |
